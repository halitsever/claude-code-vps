# RDP でリモートデスクトップに接続する

サーバーでは、RDP 経由で KDE Plasma のフルセッションが使えます。接続すると起動し、切断しても動き続けるので、次に接続したときもウィンドウはそのままです。

## クライアント

| プラットフォーム | クライアント |
| --- | --- |
| Windows | 標準のリモートデスクトップ接続（`mstsc`） |
| macOS、iOS、iPadOS | Windows App（旧 Microsoft Remote Desktop） |
| Android | Windows App または aRDP |
| Linux | Remmina。KDE なら KRDC |

`<server-ip>:53389` に接続します。xrdp にセッションの種類を聞かれたら **Xorg** を選び、作業用ユーザーの名前とパスワードでログインします。

## SSH トンネル経由で接続する

RDP の通信は暗号化されていますが、インターネットに開いたポートはスキャンの対象になります。`--rdp-private` でインストールした場合や、より安全にしたい場合は、トンネルを使います。

```bash
ssh -N -L 3389:localhost:53389 dev@<server-ip>
```

そのうえで、RDP クライアントから `localhost:3389` に接続します。外に開いているのは SSH だけになります。

すでに開けてある RDP のポートを閉じるには、次を実行します。

```bash
sudo ufw delete allow 53389/tcp
```

## 画面表示のコツ

- **解像度**はクライアントのウィンドウサイズに合わせて決まります。サイズを変えたら再接続するだけです。
- **高解像度ディスプレイ**：「システム設定」の「ディスプレイ」で拡大率を設定します。ユーザーごとに保存されます。
- **回線が遅いとき**：クライアントで色深度を16ビットに下げ、「システム設定」の「ワークスペースの挙動」でアニメーションを切ります。
- **クリップボード**：テキストなら最初から双方向でコピーできます。

## 1ユーザーにつき1セッション

xrdp は、すでに動いているセッションに再接続します。同じユーザーでローカルと RDP から同時にログインすることは Plasma ではできません。ただ、サーバーにはローカルのディスプレイがないので、この状況になることはありません。
