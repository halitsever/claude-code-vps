# Удалённый рабочий стол по RDP

На сервере работает полноценная сессия KDE Plasma, к которой вы подключаетесь по RDP. Она запускается при подключении и не закрывается, когда вы отключаетесь. В следующий раз окна будут там же, где вы их оставили.

## Клиенты

| Платформа | Клиент |
| --- | --- |
| Windows | Подключение к удалённому рабочему столу (`mstsc`), встроено в систему |
| macOS, iOS, iPadOS | Windows App (раньше Microsoft Remote Desktop) |
| Android | Windows App или aRDP |
| Linux | Remmina, в KDE также KRDC |

Подключитесь к `<server-ip>:53389`. Если xrdp спросит тип сессии, выберите **Xorg**. Войдите под своим пользователем и паролем.

## Через SSH-туннель

RDP шифруется, но открытый в интернет порт всё равно постоянно сканируют. Если вы ставили с `--rdp-private` или просто так спокойнее, пустите RDP через туннель:

```bash
ssh -N -L 3389:localhost:53389 dev@<server-ip>
```

Затем подключите RDP-клиент к `localhost:3389`. Снаружи будет доступен только SSH.

Закрыть уже открытый порт RDP можно так:

```bash
sudo ufw delete allow 53389/tcp
```

## Советы по изображению

- **Разрешение** подстраивается под окно клиента. Измените размер окна и переподключитесь.
- **HiDPI**: задайте масштаб в Параметрах системы, раздел «Экран». Настройка сохраняется для каждого пользователя.
- **Медленный канал**: уменьшите глубину цвета до 16 бит в клиенте и отключите анимацию в Параметрах системы, раздел «Поведение рабочей среды».
- **Буфер обмена** для текста работает в обе стороны сразу, без настройки.

## Одна сессия на пользователя

xrdp возвращает вас в уже запущенную сессию. Одновременно войти под одним пользователем и локально, и по RDP с Plasma не получится. На сервере такого не бывает, потому что у него нет монитора.
