# Работа с Claude Code

## Первый вход

```bash
ssh dev@<server-ip>
tmux new -s claude
claude
```

Claude Code покажет ссылку для входа. Откройте её в своём браузере, подтвердите вход и вставьте код обратно. Учётные данные остаются на сервере в `~/.claude`.

Удобнее ключ API? Экспортируйте его перед запуском:

```bash
echo 'export ANTHROPIC_API_KEY=sk-ant-...' >> ~/.bashrc
```

## tmux, чтобы работа не прерывалась

Агент, который работает целый час, не должен остановиться из-за того, что ноутбук ушёл в сон. Запустите его в tmux и отключитесь:

| | |
| --- | --- |
| Отключиться | `Ctrl-b`, затем `d` |
| Вернуться | `tmux attach -t claude` |
| Новое окно | `Ctrl-b`, затем `c` |
| Список сессий | `tmux ls` |

Готовый `.tmux.conf` включает поддержку мыши, историю на 50 000 строк и 256 цветов.

Можно также открыть Konsole на рабочем столе и выполнить там `tmux attach -t claude`. Та же сессия, только экран больше.

## Уведомления на телефон

В `~/.claude/settings.json` подключён хук `Notification`, `~/.claude/hooks/notify.sh`. Он отправляет сообщение в [ntfy.sh](https://ntfy.sh) каждый раз, когда Claude ждёт вас.

1. Установите на телефон приложение ntfy и подпишитесь на топик, который никто не угадает, например `claude-7f3k9q2m`.
2. Укажите тот же топик на сервере:

   ```bash
   echo claude-7f3k9q2m > ~/.claude/ntfy-topic && chmod 600 ~/.claude/ntfy-topic
   ```

   Или передайте `--ntfy-topic` при установке.

Топик нужно держать в секрете: любой, кто его знает, может читать ваши уведомления. Поэтому он хранится в отдельном файле и никогда не попадает в репозиторий.

## Что уже настроено

Из `dotfiles/home/.claude`:

- **`settings.json`**: тёмная тема, полноэкранный TUI, строка состояния с моделью, папкой, веткой git и заполненностью контекста, плагины, которыми я пользуюсь, и хук уведомлений
- **`CLAUDE.md`**: пустой файл для ваших глобальных инструкций. Он создаётся, только если его нет, так что ваш текст никогда не перезапишется
- **`hooks/notify.sh`**: хук ntfy, описанный выше

Меняйте что угодно у себя на компьютере и запускайте `claude-vps publish`. См. [Синхронизация настроек](/ru/guide/sync).

## Обновление Claude Code

Нативная установка обновляется сама в фоне. Обновить вручную:

```bash
claude update
```
